# odraz branding Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Brand colors across the Android UI and a bigger adaptive launcher icon.

**Architecture:** Explicit brand `ColorScheme`s (light and dark) built in `lib/theme.dart` from palette constants in `lib/design_tokens.dart`; `main.dart` stops using wallpaper (Material You) colors. The launcher icon becomes an adaptive icon (transparent hexagon foreground on a #F9FAFB background layer) plus tight-cropped legacy icons, generated by `flutter_launcher_icons` from two PNGs produced by a small Pillow script.

**Tech Stack:** Flutter 3.41.4 (Material 3), flutter_launcher_icons, Python 3 + Pillow (asset generation only).

**Spec:** `docs/superpowers/specs/2026-11-19-odraz-branding-design.md`

## Global Constraints

- Palette (hex): background/surface light `#F9FAFB`, dark `#180448`; text light `#111827`, dark `#F9FAFB`; primary light `#6B4FD8`, dark `#4DDCFF`; secondary light `#4D96FF`, dark `#6B4FD8`; tertiary light `#4DDCFF`, dark `#4D96FF`.
- The app stays locked to light mode (`ThemeMode.light`, `AdaptiveThemeMode.light`); the dark scheme is built but not enabled.
- Wallpaper (Material You / `DynamicColorBuilder`) colors must not be used for the app's `ColorScheme`.
- A saved `seed_color` preference still overrides the brand default.
- No iOS/macOS/Windows icon or theme changes; `flutter_launcher_icons` must not touch `ios/`.
- Gallery/video screens keep their functional black and white; no new `Colors.xxx` outside the files already whitelisted in `test/widgets/theme_consistency_test.dart`.
- English-only strings; no new user-visible text in this plan.

## Review Focus

1. Wallpaper colors silently winning on Android 12+: `main.dart` must not call `.harmonized()` or read `lightDynamic`/`darkDynamic` for the scheme. (Task 1)
2. A saved custom `seed_color` must still win over the brand default. (Task 1)
3. Text/background pairs readable: onPrimary/primary, onSecondary/secondary, onTertiary/tertiary at least 4.5:1, onSurface/surface at least 7:1, in both schemes. (Task 1)
4. Adaptive icon foreground hexagon not clipped by a circular launcher mask: every opaque pixel within 335 px of the center of the 1024 px layer. (Task 2)
5. iOS files untouched by the icon generator. (Task 2)
